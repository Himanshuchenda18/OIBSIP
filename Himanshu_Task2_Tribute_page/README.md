# Ratan Tata Tribute Page

## Project Overview

This project is a tribute website dedicated to Ratan Tata, one of India's most respected industrialists, leaders, and philanthropists.

The purpose of this project is to showcase his inspiring life journey, achievements, leadership qualities, and contribution towards society through a visually appealing and responsive webpage.

This project was developed as part of the Oasis Infobyte Web Development Internship Task 2.



## Features

- Modern and responsive tribute webpage
- Attractive hero section with profile image
- Detailed biography sections
- Early life and leadership journey
- Major achievements showcase
- Inspirational quote section
- Personal admiration section
- Professional dark and gold theme
- Smooth scrolling interaction
- Mobile-friendly design



## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
