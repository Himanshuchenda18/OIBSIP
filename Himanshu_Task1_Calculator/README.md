# Calculator Pro - Advanced Scientific Calculator

## About The Project

Calculator Pro is a modern and interactive web-based calculator developed using HTML, CSS, and JavaScript.

The main aim of this project is to create a fully functional calculator with a professional user interface and additional advanced features. Along with basic mathematical operations, this calculator also supports scientific operations, memory functions, keyboard controls, and a responsive design that works across different screen sizes.

This project was developed as part of the OIBSIP Web Development Internship.


## Features

### Basic Calculator Operations

- Addition
- Subtraction
- Multiplication
- Division
- Percentage calculation
- Decimal calculations


### Scientific Calculator Features

- Square root calculation (√)
- Square operation (x²)
- Power calculation (xʸ)
- Reciprocal calculation (1/x)
- Pi value support (π)
- Parentheses operations


### Memory Functions

The calculator provides memory features for better usability:

- MC - Clear stored memory
- MR - Recall stored value
- M+ - Add current value to memory
- M- - Subtract current value from memory


### Keyboard Support

The calculator can also be controlled using the keyboard.

Supported controls:

- Numbers (0-9)
- Mathematical operators (+, -, *, /)
- Enter key for calculation
- Backspace for deleting input
- Escape key to clear the display

## How To Run The Project

1. Download or clone this repository.

2. Open the project folder in Visual Studio Code.

3. Open the `index.html` file.

4. Run the project using Live Server.

5. The calculator will open in your browser.
