# FocusTasks Pro

## Project Overview

FocusTasks Pro is a modern and responsive To-Do Web Application designed to help users organize their daily activities efficiently. The application provides an easy way to create, manage, edit, and track tasks while maintaining a clean and visually appealing interface.

The project focuses on improving productivity by allowing users to separate pending and completed tasks, monitor their progress through statistics, and personalize their experience using multiple beautiful themes such as Default, Dark, Ocean, Neon, Minimal, and Glass.

This project was developed as part of the Oasis Infobyte Web Development Internship.

---

## Features

- Add new tasks with category, priority, and due date
- Edit existing tasks anytime
- Delete individual tasks
- Mark tasks as completed
- Separate sections for Pending Tasks and Completed Tasks
- Search tasks instantly
- Filter tasks by:
  - All Tasks
  - Pending Tasks
  - Completed Tasks
- Sort tasks by:
  - Latest First
  - Priority
  - Due Date
- Dynamic progress bar
- Real-time statistics dashboard
- Multiple themes:
  - Default Theme
  - Dark Theme
  - Ocean Theme
  - Neon Theme
  - Minimal Theme
  - Glass Theme
- Responsive design for desktop, tablet, and mobile devices
- Local Storage support to save tasks permanently
- Smooth animations and modern UI

## Website Sections

### Header Section

Contains the website logo, application title, tagline, and theme selector for changing the appearance of the application.

### Hero Section

Displays an introduction to the application along with a progress card that shows the user's current completion percentage.

### Statistics Dashboard

Shows important productivity statistics including:

- Total Tasks
- Completed Tasks
- Pending Tasks
- Success Rate

### Task Creation Section

Allows users to:

- Enter task title
- Select category
- Choose priority level
- Set due date
- Add a new task

### Search and Filter Section

Provides functionality to:

- Search tasks instantly
- Sort tasks
- Filter by status

### Pending Tasks Section

Displays all tasks that are yet to be completed.

Users can:

- Edit tasks
- Delete tasks
- Mark tasks as completed

### Completed Tasks Section

Displays all successfully completed tasks.

Users can:

- Edit completed tasks
- Delete completed tasks

### Theme System

Users can personalize the application using different themes:

- Default
- Dark
- Ocean
- Neon
- Minimal
- Glass

Each theme changes the overall colors, cards, backgrounds, buttons, and interface to provide a unique experience.
